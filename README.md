# Reflection Summary

The goal of this activity is for students to build a food ordering app and make design decisions using an ai assisted workflow. Another important part of this tinker is being able to make custom agents for specific projects. I think the key concept learned is how to translate the written specification into a structured set of classes to be able to accomplish the goals. I think a common pain point might be in deciding which classes to create. I remember the first time I did this it was a little difficult and the group may have different ideas. I would guide a student by asking them to talk through their thought process and facilitating conversation to make sure everyone in the room can understand why we make certain classes.
